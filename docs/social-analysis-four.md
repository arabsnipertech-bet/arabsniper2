# Four-match sports editorial

Each existing match-publication window now projects up to four distinct, unstarted fixtures with data updated within 90 minutes and at least four valid full-time observations per team. No odds, recommended markets, EV or betting tier determines eligibility or order. Major first divisions are prioritized, then sample completeness and freshness. Empty or short windows remain explicit; duplicates from prior posts are excluded.

Cards report model goal means, first/second-half means when supported, historical scored/conceded means and sample sizes. They do not provide betting recommendations. The underlying model is unchanged. Existing educational and promotional slots are not modified.

One sports-only live per Rome day is reserved among the presented afternoon/evening fixtures, subject to verified API event coverage. A confirmed Telegram publication receipt must match its token before monitoring starts. The external Fast backup dispatches/restarts the separate sports workflow. Scores need two matching observations at least 45 seconds apart. Conditional R2 state writes prevent concurrent sends; uncertain Telegram delivery stops for reconciliation instead of retrying blindly. Provider outages do not generate inferred scores. A previous consumed legacy live blocks a second daily reservation during transition.
